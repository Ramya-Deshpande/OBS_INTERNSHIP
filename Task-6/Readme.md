Title:Predicting fuel efficiency with ML

This project analyzes the Auto MPG dataset to understand the relationship between different features and vehicle fuel efficiency. It leverages Python libraries such as Pandas, NumPy, Seaborn, and Matplotlib for data manipulation and visualization.

Project Structure:
1.Data Loading and Exploration:
Load the dataset using Pandas.
Perform basic data exploration and visualization.

2.Data Preprocessing:
Feature engineering and transformation.

3.Model Training and Evaluation:
Train a machine learning model.
Evaluate the model's performance using loss and Mean Absolute Error (MAE).

Dependencies
1.Python
2.Pandas
3.NumPy
4.Seaborn
5.Matplotlib
